# Release preparation and roadmap

## v0.1.0 scope

Dependency-free endpoint geometry, synthetic example, optional image inference,
optional ZED live adapter, core tests, and project-specific CI. No research data
or weights. The camera and real checkpoint paths require validation.

## Before publishing

- Review the public source archive generated by `tools/build_public_bundle.py`.
- Confirm permission to release the extracted research implementation with your
  institution/collaborators where relevant. Add the correct maintainer identity,
  repository URL and thesis citation when available; none are invented here.
- Run core tests in a clean environment. Test the vision extra separately before
  claiming checkpoint support; the original pinned framework is not a lockfile.
- Do not upload `.local`, the parent workspace, private data or IDE configuration.
- Keep AGPL license and upstream provenance. Check separate permissions before
  adding any checkpoint, photo, video, label or derived training image.
- Hardware limitations and no validated accuracy must remain visible in README.

## Next milestones

1. Recover endpoint definitions and establish one tested fish checkpoint.
2. Publish an authorized tiny paired image/XYZ fixture and a model card.
3. Validate ZED retrieval, alignment and depth quality on actual hardware.
4. Add robust depth sampling and uncertainty/validity-rate evaluation.
5. Restore exact training configs and publish a defensible experimental protocol.
6. Add curved-body measurement only after defining and validating centreline points.

Speed, acceleration and ArcFace identification are intentionally outside this
release. Existing historical results are not transferred as verified benchmarks.

## v0.2.0: training and validation

Adds local train/val CLI, a documented two-endpoint YOLOv8n Pose baseline, a dataset
template and annotation/training tutorial. Core tests include mocked training
dispatch and dry-run behavior. No real training or benchmark is included. The
public source archive is named fish-length-estimation-0.2.0-source.zip.

## v0.3.0: data checks and physical-length evaluation

Adds dependency-free read-only annotation checks and exact cross-split hashing,
plus explicit-pair physical-length errors and valid-measurement coverage. Examples
are synthetic. No new experimental results, data or checkpoints are distributed.
See CHANGELOG.md and the two command guides.
